# 📊 香港暈倒及倒斃新聞互動圖表（2018 至今）
將「香港暈倒及倒斃新聞詳細清單」由 2018 年 1 月至 2026 年 10 月共 3,353 宗新聞個案，整理成可以自己操作的互動圖表。
# 主要功能
- 時間範圍可調：可以揀 1 個月、3 個月、6 個月、1 年、3 年、5 年或全部，亦可以在圖上拖曳放大，雙擊還原。
- 人數走勢：顯示死亡及暈倒人數，附 7 天、30 天、180 天移動平均線。
- 多角度分佈：性別與年齡、18 區、發生位置、運動項目。
- 標準差統計：按年份顯示每日人數和年齡的平均值及標準差。
- 互動篩選：點擊任何圖表的長條，其他圖表、統計和列表都會一齊跟住更新。
- 詳細個案列表：可以搜尋、排序，並直接按標題開啟原始新聞連結。
🔗 網址： https://tonyrangerhk-rgb.github.io/suddendeathhk/

# 使用提示
- 資料來自新聞報道整理，並非官方完整統計，所以不能單憑數字推論發生率或成因。
- 2018 至 2021 年遇溺新聞未有完整收錄，早年數字偏低，不宜直接與近年比較。
- 數據屬於靜態資訊, google sheet 更新後仍需要作者手動更新
- 資料來源：https://docs.google.com/spreadsheets/d/1wehAQbROa5ew-SFlyKevXELA5KL3zLqBE4k5LwWiqfc/edit?usp=sharing
